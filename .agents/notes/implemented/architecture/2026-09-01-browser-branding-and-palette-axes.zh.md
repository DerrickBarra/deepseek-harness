# Agent Note: 浏览器产品标识与正交配色轴

Status: implemented

[English](2026-09-01-browser-branding-and-palette-axes.md) | 中文

## 问题

Web 客户端曾在三个渲染持有方中硬编码发行版字标、鱼形标识和产品标题，而 `ui-theme` 把每组已注册 token 视为一项具体的浅色或深色主题。Agent 专属 PWA 图标已有独立的构建时持有方，但浏览器插件缺少由发行版持有的应用内身份接缝，也没有与浅色、深色和跟随系统相互独立的持久配色选择。

## 决策

`@deepseek-ai/dsh-client-branding` 是始终组合、与 React 无关的浏览器服务。它接受以不透明 `BrandingSourceId` 为键的普通数据贡献，其中包含 `displayName`、`productTitle` 和可选 `iconUrl`；通过 `getSnapshot` 和 `subscribe` 发布不可变、带 revision 的快照，并返回可安全替换的 disposer。其 `/client` Loader 入口的运行时值仅导出 `apply` 与 `name`，实现状态保持内部可见。最新贡献优先；释放后显露前一项贡献或发行版默认值。浏览器插件通过 `ctx.effect` 持有注册。应用壳、侧边栏与会话根组件经框架持有的 hook 绑定 observable，并只向呈现组件传递派生数据。没有自定义 URL 时，原有 `BrandWordmark`、`FishLogo` 和 `DeepSeek Harness` 标题保持完全不变。PWA manifest 图标不属于此服务。

`ui-theme` 保留 `light`、`dark` 和 `system` 作为明暗偏好，并增加独立的持久 `ThemePaletteId`。每个 `PaletteDefinition` 为其覆盖的每个 token 提供浅色与深色值。配色注册可逆，但删除所选注册不会重写设置：渲染方使用默认配色、在快照中标记缺失、保留请求的 id，并在同一 id 再次注册时自动恢复。注册值与发布的自定义值都会被防御性复制并深度冻结。

“自定义”是内建配色，为两种模式各提供六个语义角色：强调色、应用背景、浮层、侧边栏、主要文本和次要文本。值采用严格 `#RRGGBB` 语法。编辑器通过嵌套的 `settings.appearance.item` slot 贡献，每次只显示一个由原生按钮切换的浅色或深色标签面板，并提供 WAI-ARIA 标签状态以及方向键、Home 和 End 键导航。同一份成对草稿在标签切换时保留，并支持原生颜色输入、直接十六进制编辑、实时预览、保存、重置和取消。无效草稿保持可见但不能预览或保存。预览是一项按来源区分的 token 覆盖，会在取消、已接受保存、组件卸载或插件 fiber 释放时撤回。保存写入完整自定义对象，并且只在设置回读一致后清除草稿。不增加对比度警告或评分层。

Host 引导脚本嵌入持久明暗偏好、配色 id 与自定义值。选择“自定义”时，它在加载壳绘制前应用别名。只由浏览器注册的配色在客户端注册激活前有意显示默认值，因为 Host 不持有该注册表。

## 考虑过的替代方案

**把产品标识放进 slot。** Slot 承载渲染组合，这会让标题投影和多个保留默认图标的位置依赖 React 值身份。与 React 无关的 observable 服务把身份保留为普通数据，并允许每个发行版持有方选择自己的默认图稿。

**用配色 id 替换浅色、深色和跟随系统。** 这会把操作系统明暗解析与 token 样式混为一体、破坏 body 绘制前的引导，并迫使每套配色重复明暗选择。两个独立轴保留既有明暗行为。

**插件卸载时清除所选配色。** 这会让 HMR 与 fleet 插件暂时缺席产生破坏性结果。缺席时保留持久 id 并解析为默认值，使注册生命周期保持可逆。

**增加对比度评分或颜色库。** 所需编辑器需要严格语法与原生选择器，而不是无障碍策略。警告层不能阻止用户保存预期颜色，却会引入不受支持的产品语义与依赖。

## 后果

产品标识保持 JSON 兼容，不能携带 React node、标记或 PWA manifest 策略。消费者不手动订阅，也不接收 Cordis context。配色与明暗可独立选择。暂时缺席的 fleet 配色能跨重启保留在设置中，且不会留下陈旧内联 token。这六个自定义角色明确不承诺可访问性对比度，也不覆盖每个状态和交互别名。

## 取代关系检查

本说明扩展已实现的 Web 客户端架构与 slot 类型链说明，但不取代其持有规则。它替换 `ui-theme` README 中“已注册主题 id 是非持久具体偏好”的陈述；浅色、深色和跟随系统仍是唯一明暗偏好，已注册配色 id 则形成持久且正交的轴。
